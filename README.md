## ⚡ Quick Start

### Prerequisites
- XAMPP (Apache 3.3.0 + MySQL 8.0 + PHP 8.1)
- Composer
- Git

### Installation

1. **Clone & Setup**
```bash
cd C:\xampp\htdocs\qly_hthao
composer install
cp .env.example .env
php artisan key:generate
php artisan jwt:secret
```

2. **Database**
```bash
# Create database: quanly_hoithao
php artisan migrate
php artisan db:seed --class=LookupTablesSeeder
php artisan db:seed --class=SampleDataSeeder
```

3. **Test API**
```bash
curl http://localhost/qly_hthao/qlyhoithao/public/api/health
```

**Base URL:** `http://localhost/qly_hthao/qlyhoithao/public/api`
