🚀 Tính năng chính

1. Trang quản lý kỷ yếu cho Chair:
- Xem danh sách bài báo đã chấp nhận
- Cập nhật số trang cho từng bài báo
- Xuất bản bài báo (chuyển trạng thái thành "PUBLISHED")
- Thống kê tổng quan về proceedings

2. Trang kỷ yếu công khai:
- Hiển thị tất cả bài báo đã xuất bản
- Mục lục với thông tin tác giả và số trang
- Liên kết tải PDF từng bài báo
- Thống kê tổng quan

3. Tích hợp với Chair Dashboard:
- Menu "Xuất bản kỷ yếu" trong sidebar
- Thống kê kỷ yếu trong trang chi tiết hội thảo
- Nút truy cập nhanh từ header hội thảo

🎯 Cách sử dụng

Đối với Chair:
1. Đăng nhập với tài khoản Chair
2. Vào menu "Xuất bản kỷ yếu" hoặc click vào hội thảo → "Quản lý kỷ yếu"
3. Cập nhật số trang cho các bài báo đã chấp nhận
4. Chọn và xuất bản các bài báo đã sẵn sàng
5. Xem kỷ yếu công khai để kiểm tra kết quả

Routes cần test:
- /chair/proceedings/{conferenceId} - Quản lý kỷ yếu
- /chair/proceedings/{conferenceId}/show - Xem kỷ yếu công khai

📊 Database Info

Bảng 'baibao' có:
- 27 bài báo tổng cộng
- Cột decision cho trạng thái ACCEPTED/PUBLISHED
- Cột page_start và page_end cho phân trang
- Cột published_at cho thời gian xuất bản

Note: Cần có ít nhất một bài báo với decision = 'ACCEPTED' để test đầy đủ tính năng

🧪 Test Commands

Để test hệ thống, chạy các lệnh sau:

# Kiểm tra routes
php artisan route:list | grep proceedings

# Kiểm tra có bài báo nào đã chấp nhận
php artisan tinker --execute="DB::table('baibao')->where('decision', 'ACCEPTED')->count()"

# Tạo dữ liệu test (nếu cần)
php artisan tinker --execute="DB::table('baibao')->where('paper_id', 1)->update(['decision' => 'ACCEPTED'])"
